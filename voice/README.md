# 声音使用规范（克隆声）

> 声纹是生物特征数据：**参考音频一律只存私有仓库/私有服务器，绝不公开**。
> 本目录只公开「用法」：配置、脚本、参数。

## 配置
- 引擎: IndexTTS-2.5（B站官方开源，零样本克隆）
- 参考音频: 安静环境、自然语速、55秒科普口播（存于私有库 assets/）
- 语气: **默认正常**（情绪版实测不自然，已列入禁忌清单 #11）
- 语速: 320-350字/分钟（默认即达标）
- 段间停顿: 0.28s
- BGM 音量: 0.13（约 -19dB），结尾 2.5s 淡出

## 日常生成
python gen.py "要念的文案" 输出.wav [--speed 1.0] [--device cpu]

## 换更好的参考
零样本上限=参考音频质量。安静房间+自然语速重录 1-2 分钟，替换私有库里的
ref_voice.wav 即可。
