# 科普视频生产流程 SOP

B 站科普频道「小胃袋王子」的视频生产方法论，持续迭代中。

基于两期实战 + 三支爆款逆向解剖（注意力机制量化、82 段运动语言实测）+ whisper 字幕强制对齐管线。

## 为什么开源这套流程

- **AI 只当工具人**：画面素材零 AI 生成、声音是本人克隆声、判断全部归人
- **所有经验数值化**：推多少、停多久、语速多少，没有"凭感觉"环节
- **禁忌驱动**：用户每说一次"不要"就固化成规范，永不再犯

## 仓库结构

| 文件 | 内容 |
|---|---|
| `SOP.md` | 生产全流程规范（选题/文案/声音/画面/运动语言/数据复盘） |
| `禁忌清单.md` | ⛔ 全部"不要"的固化指令 + 交付前 Checklist |
| `voice/` | 声音使用规范与生成脚本（声纹本体不公开，见目录内说明） |
| `subtitle/` | whisper 强制对齐字幕引擎 |

## 核心原则（三句话）

1. **AI 不进证据链**：画面里的一切都是真的，声音是真的你
2. **运动语言**：0.5s 快推 → 绝对静止 → 硬切（匀速 Ken Burns 是反模式）
3. **产能**：人工 40 分钟 + 机器 20 分钟 = 一期
